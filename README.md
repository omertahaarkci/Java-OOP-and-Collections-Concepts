# Java OOP & Collections Concepts 🚀

Bu depo, Java programlama dilinde Nesne Yönelimli Programlama (OOP) prensiplerini ve Java Collections Framework yapısını kavramak amacıyla geliştirdiğim temel pratikleri ve veri yapıları çalışmalarını içerir.

## 🛠️ İçerik ve Proje Yapısı

Proje içerisindeki kodlar `oop_concepts` paketi altında mantıksal rollerine göre ayrılmıştır:

### 1. Nesne Yönelimli Programlama (OOP)
* **Person.java:** Kapsülleme (Encapsulation) ve Constructor (Yapıcı Metot) mimarisini barındıran temel veri modeli sınıfı.
* **PersonListManagement.java:** Sınıf modellerini dinamik listelerde yönetme, nesne referansları ile çalışma ve fonksiyonel veri aktarımı simülasyonu.

### 2. Java Collections Framework (Veri Yapıları)
* **ArrayListFundamentals.java:** Dinamik dizilerin (ArrayList) yönetimi, listeyi sıralama (Collections.sort), ters çevirme ve bellek optimizasyonu işlemleri.
* **ArrayListElementManipulation.java:** Döngüler içerisinde indeks bazlı veri manipülasyonu ve listenin dinamik olarak yeniden boyutlandırılması pratikleri.
* **HashMapGradeMapping.java:** Anahtar-Değer (Key-Value) eşleşmesiyle çalışan HashMap mimarisi üzerinde veri arama ve eşleme performansı çalışması.
* **HashSetUniqueElements.java:** Benzersiz (Unique) elementlerin tutulduğu, tekrarlanan verileri engelleyen HashSet veri yapısının analizi.

## 💻 Kazanımlar
Bu çalışmaları tamamlayarak; veri yönetimi, bellekte nesne referanslarının tutulma mantığı ve temel Java veri yapılarının hangi senaryolarda optimize çalışacağını pratik ettim.
